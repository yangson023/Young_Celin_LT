#### 知识点 1-1-1

**知识点名称：** 矩阵的概念与基本运算（加法、数乘、乘法、转置）

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.1 矩阵及其运算

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 矩阵是数表的推广，有加法、数乘、乘法和转置四种基本运算，乘法是最特殊的一种。

**核心内容：**
矩阵是由 m×n 个数排成的矩形数表。基本运算包括：(1) 加法：同型矩阵对应元素相加；(2) 数乘：每个元素乘以同一个数；(3) 乘法：A 的列数必须等于 B 的行数，乘积元素 C_ij = Σ a_ik b_kj；(4) 转置：行列互换，(A^T)^T = A，(AB)^T = B^T A^T。矩阵运算满足结合律和分配律，但乘法一般不满足交换律。

**关键公式：**
- C_ij = Σ_{k=1}^{p} a_ik b_kj（A为m×p, B为p×n时）
- (AB)^T = B^T A^T

**适用条件：**
- 加法/减法：A和B必须同型（行数相同且列数相同）
- 乘法：A的列数 = B的行数
- 转置：适用于任意矩阵

**常见易错点：**
- 矩阵乘法不满足交换律：AB ≠ BA（一般情况）
- 矩阵乘法不满足消去律：AB = AC 不能推出 B = C
- 转置的顺序：(AB)^T = B^T A^T，不能写成 A^T B^T
- 零矩阵与数字0不同，零矩阵可以和任何同型矩阵相加

**适合题型：** single_choice, true_false

**来源依据：** 教材1.1（矩阵概念、线性运算、乘法、转置）；讲座 ch1-ch2-difficulties Page 11

**人工审核提醒：** 教材中矩阵乘法的定义使用了求和符号 Σ，网页展示时需确认符号渲染方式。

#### 知识点 1-1-2

**知识点名称：** 矩阵乘法的特殊性——不满足交换律与消去律

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.1 矩阵及其运算

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是

**一句话理解：** 矩阵乘法与普通数乘法有四条差异，学生最容易在这上面犯错。

**核心内容：**
四点关键差异：(1) 不满足交换律：AB ≠ BA，除非A和B可交换；(2) 必须区分左乘和右乘：AB-B = (A-E)B ≠ B(A-E)；(3) 幂运算与展开公式不成立：(AB)^k ≠ A^k B^k，(A+B)(A-B) ≠ A^2-B^2；(4) 不满足消去律：AB=0 不能推出 A=0 或 B=0。

**关键公式：**
- AB ≠ BA（一般情况）
- (A+B)(A-B) ≠ A^2 - B^2
- AB = 0 ⇏ A = 0 或 B = 0

**适用条件：** 所有涉及矩阵乘法等式的判断。只有在 A 和 B 可交换（AB=BA）时，上述等式才可能成立。

**常见易错点：**
- 习惯性把数的乘法规律套用到矩阵上
- 因式分解时忘记区分左乘和右乘
- 见到 AB=0 就认为至少一个为零矩阵

**适合题型：** single_choice, true_false

**来源依据：** 讲座 ch1-ch2-difficulties Page 11（矩阵乘法与普通数乘法的异同）；lecture Page 22-27

**人工审核提醒：** 建议配合具体数值矩阵的判断题出题。

#### 知识点 1-1-3

**知识点名称：** 特殊矩阵（零矩阵、单位矩阵、对角矩阵、三角矩阵、对称矩阵）

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.1 矩阵及其运算

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 几种特殊矩阵在运算中有简化规则，是后续学习的基础工具。

**核心内容：**
(1) 零矩阵 O：所有元素为0，A+O=A，AO=O。
(2) 单位矩阵 I（或E）：主对角线为1其余为0，AI=IA=A。
(3) 对角矩阵：非主对角线元素均为0，对角矩阵相乘只需将对角元对应相乘。
(4) 上（下）三角矩阵：主对角线以下（以上）均为0，同类型的三角矩阵乘积仍为同类型三角矩阵。
(5) 对称矩阵：A^T = A（a_ij = a_ji）；反对称矩阵：A^T = -A（a_ij = -a_ji，且 a_ii = 0）。

**关键公式：**
- I·A = A·I = A
- A^T = A（对称矩阵定义）
- O·A = A·O = O（仅当维数匹配时）

**适用条件：**
- 单位矩阵必须为方阵
- 对称/反对称矩阵必须为方阵
- 零矩阵与A相乘时需维数匹配

**常见易错点：**
- 反对称矩阵的对角元必须为零（a_ii = -a_ii ⇒ a_ii = 0）
- 三角矩阵的乘积不一定是对角矩阵
- 对称矩阵的和仍为对称矩阵，但乘积不一定对称

**适合题型：** single_choice, true_false

**来源依据：** 教材1.1；讲座 lecture Page 3-8

**人工审核提醒：** 讲座中提到的"幂等矩阵""幂零矩阵"等特殊矩阵性质较深，建议在第五章特征值中再讲。

#### 知识点 1-2-1

**知识点名称：** 高斯消元法——用初等行变换解线性方程组

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.2 高斯消元法与矩阵的初等变换

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 通过三种行变换将增广矩阵化为行阶梯形，回代求出全部解。

**核心内容：**
高斯消元法步骤：(1) 写出增广矩阵 (A|b)；(2) 用三种行初等变换（交换两行、某行乘以非零数、某行加上另一行的倍数）将系数矩阵化为行阶梯形；(3) 判断解的情况——若出现 0=非零数 则无解，否则有解；(4) 继续化为行最简形；(5) 确定主元变量和自由变量，写出通解。自由变量个数 = 未知量个数 - 主元个数。

**关键公式：**
- 自由变量个数 = n - 主元个数（n为未知量个数）

**适用条件：** 适用于任意线性方程组（不限于方阵）。

**常见易错点：**
- 解方程组只能用行初等变换，不能用列初等变换
- 化为行最简形时主元列其余元素必须全为零
- 自由变量取任意常数而非固定值

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材1.2（高斯消元法、矩阵的初等变换）；讲座 lecture 页

**人工审核提醒：** 确认教材中对"行阶梯形"和"行最简形"的严格定义。

#### 知识点 1-2-2

**知识点名称：** 初等矩阵——左乘行变、右乘列变

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.2 高斯消元法与矩阵的初等变换

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 对矩阵A做行初等变换等同于左乘对应的初等矩阵，列变换等同于右乘。

**核心内容：**
三种初等矩阵对应三种初等变换：
(1) E(i,j)：交换第i行与第j行得到的矩阵，左乘→交换行，右乘→交换列。
(2) E(i(k))：第i行乘以非零数k，要求k≠0。
(3) E(i,j(k))：第i行加上第j行的k倍。
记忆口诀：**左行右列**。初等矩阵都可逆，逆矩阵仍为同类型初等矩阵。

**关键公式：**
- 行变换 → 左乘初等矩阵
- 列变换 → 右乘初等矩阵
- E(i,j)^(−1) = E(i,j)；E(i(k))^(−1) = E(i(1/k))；E(i,j(k))^(−1) = E(i,j(−k))

**适用条件：** 初等矩阵来源于对单位矩阵做一次初等变换，必须是方阵。

**常见易错点：**
- "左乘行变、右乘列变"方向记反
- 解方程组时错误使用列初等变换（只能用行变换）
- 初等矩阵的逆矩阵类型和参数搞错（特别是倍加型的符号）

**适合题型：** single_choice, true_false

**来源依据：** 教材1.2（初等矩阵）；讲座 ch1-ch2-difficulties Page 67-69

**人工审核提醒：** 教材中初等矩阵的记号可能与讲座不同（如P(i,j)等），请统一。

#### 知识点 1-3-1

**知识点名称：** 逆矩阵的定义与基本性质

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.3 逆矩阵

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 若方阵A存在B使AB=BA=I，则A可逆且B=A^(-1)；逆矩阵唯一且(A^(-1))^(-1)=A。

**核心内容：**
(1) 定义：n阶方阵A若存在n阶方阵B使得AB=BA=I，则A可逆，B为A的逆矩阵。
(2) 逆矩阵唯一：若A可逆则逆矩阵唯一。
(3) 基本性质：(A^(-1))^(-1)=A；(kA)^(-1)=(1/k)A^(-1)（k≠0）；(AB)^(-1)=B^(-1)A^(-1)（注意顺序）；(A^T)^(-1)=(A^(-1))^T。
(4) 求法：用行初等变换法——(A|I) → (I|A^(-1))。

**关键公式：**
- AA^(-1) = A^(-1)A = I
- (AB)^(-1) = B^(-1) A^(-1)
- (A^T)^(-1) = (A^(-1))^T

**适用条件：** 仅方阵可讨论可逆性。非方阵AB=I不能称A可逆。

**常见易错点：**
- (AB)^(-1) = B^(-1)A^(-1)，不能写成 A^(-1)B^(-1)
- 非方阵看到AB=I就以为A可逆
- 用行初等变换求逆时必须同时变换到I

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材1.3（逆矩阵的概念与性质、行初等变换求逆）

**人工审核提醒：** 讲座中"非方阵左逆/右逆"属于拓展内容，建议放在1.4分块矩阵作为扩展。

#### 知识点 1-3-2

**知识点名称：** 从条件等式构造逆矩阵——因式分解法

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.3 逆矩阵

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是

**一句话理解：** 遇到A+B=AB等条件时，两边同时加I再因式分解，可推出可逆性和可交换性。

**核心内容：**
典型题型：已知 A+B = AB。求解思路：(1) 移项：AB-A-B = O；(2) 两边加I：AB-A-B+I = I；(3) 因式分解：(A-I)(B-I) = I；(4) 结论：A-I 可逆且 (A-I)^(-1) = B-I。由 (A-I)(B-I) = (B-I)(A-I) = I，展开得 AB = BA。
推广：若 AB = αA + βB（α≠0, β≠0），则 A 与 B 可交换。

**关键公式：**
- A+B = AB ⇒ (A-I)(B-I) = I
- AB = αA + βB ⇒ (1/αβ)(A-βI)(B-αI) = I

**适用条件：** 已知含有矩阵加减乘的等式，目标为证明可逆性或交换性。

**常见易错点：**
- 忘记加I项（最关键的一步容易被忽略）
- 因式分解时符号出错（如(A-I)(B-I)=AB-A-B+I，容易丢I）
- 展开验证时 (A-I)(B-I)=(B-I)(A-I) 这一步容易被忽略

**适合题型：** basic_calculation, single_choice

**来源依据：** 讲座 ch1-ch2-difficulties Page 38-41（例10）

**人工审核提醒：** 教材复习题一中有类似题目，请对照教材确认题号。

#### 知识点 1-3-3

**知识点名称：** 方阵的幂与幂零矩阵求逆（华罗庚恒等式）

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.3 逆矩阵

**教学层级：** 拓展提高

**是否建议进入第一版网页：** 否

**一句话理解：** 若 A^k = O，则 I-A 可逆，其逆为 I+A+A^2+…+A^(k-1)（类比等比数列求和）。

**核心内容：**
当矩阵A满足A^k = O（k为正整数，称为幂零矩阵）时，构造恒等式：
I = I - A^k = (I-A)(I+A+A^2+…+A^(k-1))
因此 I-A 可逆且逆矩阵为I+A+…+A^(k-1)。这一技巧可类比数的泰勒展开 1/(1-x) = 1+x+x^2+…（仅为启发，非严格证明）。

**关键公式：**
- A^k = O ⇒ (I-A)^(-1) = I + A + A^2 + … + A^(k-1)

**适用条件：** A为方阵且满足 A^k = O（幂零矩阵）。

**常见易错点：**
- 只有 A^k = O 时公式才成立，不能乱用
- 与泰勒展开的类比只是启发性的

**适合题型：** basic_calculation（提高类题目）

**来源依据：** 讲座 ch1-ch2-difficulties Page 26-27（例4）

**人工审核提醒：** 讲座中此知识点被称为"华罗庚恒等式"，但教材中可能不以此名称出现。建议在网页中标注为拓展内容。

#### 知识点 1-4-1

**知识点名称：** 分块矩阵的基本运算规则

**所属章节：** 第一章 矩阵及其初等变换

**所属小节：** 1.4 分块矩阵

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 将大矩阵分割成小块后，只要分块方式匹配，加法、数乘、乘法规则与普通矩阵一致。

- 分块乘法时各块的顺序不能随意调整

**知识点名称：** n阶行列式的定义

**所属章节：** 第二章 行列式

**是否建议进入第一版网页：** 是

**一句话理解：** n阶行列式是所有取自不同行不同列的n个元素的乘积的代数和（带正负号）。

**适用条件：** 仅方阵有行列式。

- 行列式与矩阵本身混淆（行列式是一个数，矩阵是一张表）
- 三阶以上不能用对角线法则
- 代数余子式的符号 (-1)^(i+j) 容易忘

#### 知识点 2-2-1

**知识点名称：** 行列式的性质

**所属章节：** 第二章 行列式

**所属小节：** 2.2 行列式的性质与计算

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 六条核心性质是化简和计算行列式的理论基础。

**核心内容：**
六大性质：(1) 转置不变：|A^T| = |A|。(2) 换行变号：交换两行（列），行列式变号。(3) 公因子提取：某行（列）有公因子k，可提到行列式外。(4) 倍加不变：某行（列）加上另一行（列）的k倍，行列式不变。(5) 拆分行列式：某行（列）元素为两数之和，可拆分为两个行列式之和。(6) 若两行（列）成比例，行列式为零（|A|=0 ⇔ 行列向量线性相关）。

**关键公式：**

**适用条件：** n阶方阵。

**常见易错点：**
- |kA| = k^n|A| 中的指数 n 容易写成 1（这是最常见的错误之一）
- 倍加变换保持行列式不变（只变被加行），和公因子提取区分清楚
- 两条性质"某行为两数之和"和"某行为倍数"不要混淆

**适合题型：** single_choice, true_false, basic_calculation

#### 知识点 2-2-2

#### 知识点 2-3-1

**知识点名称：** 拉普拉斯定理——行列式按k行展开

**所属章节：** 第二章 行列式

**适用条件：** n阶行列式，k为1到n-1之间的正整数。

**常见易错点：**
- 代数余子式的符号容易忘记或算错
- 子式与余子式的阶数搞反
- 选择和为k的子式数较多时容易漏项

#### 知识点 2-4-1

**知识点名称：** 克拉默法则——用行列式解线性方程组

**所属章节：** 第二章 行列式

**所属小节：** 2.4 克拉默法则

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是（重点考点）

**一句话理解：** 若系数矩阵A为n阶方阵且|A|≠0，则Ax=b的唯一解中 x_i = |A_i|/|A|。

**核心内容：**
克拉默法则：(1) 用于求解n个方程n个未知数的线性方程组Ax=b，前提是|A|≠0。(2) A_i 为将A的第i列替换为常数向量b。(3) 解为 x_i = |A_i|/|A|。(4) 推论：齐次方程组 Ax=0 有非零解 ⇔ |A|=0。(5) 局限：需计算n+1个n阶行列式，n较大时不实用，但理论意义重大——证明了解的唯一性与行列式的等价关系。

- x_i = |A_i| / |A|（A_i为A第i列换成b，|A|≠0）

- 忘记验证 |A|≠0 这个前提条件

- 考试中通常考n=3的计算题

#### 知识点 2-5-1

#### 知识点 2-5-3

**知识点名称：** 矩阵等价与行等价、列等价的区别

**所属章节：** 第二章 行列式

**所属小节：** 2.5 矩阵的秩

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是

**一句话理解：** 矩阵等价只需 R(A)=R(B)（同型）；行等价要求A可经行变换化为B（行向量组等价）；矩阵等价用行列两种变换。

**核心内容：**
(1) 矩阵等价：A与B同型且R(A)=R(B)，意味着存在可逆P,Q使PAQ=B。(2) 行等价：A可经有限次行初等变换变为B，此时行向量组等价，但列向量组只是有相同的线性关系（不等价）。(3) 列等价：A可经有限次列初等变换变为B，类似地列向量组等价。(4) 重要的是：矩阵等价（行列变换都用）时，行和列向量组都可能不等价。判断向量组等价还需要验证 R(A) = R(B) = R(A, B)。

**关键公式：**
- 矩阵等价：R(A) = R(B)（A, B同型）
- 向量组等价：R(A) = R(B) = R(A, B)

**适用条件：** 矩阵等价要求A,B同型；向量组等价对应向量个数可不同。

**常见易错点：**
- 把矩阵等价的充要条件 R(A)=R(B) 误用到向量组等价
- 向量组等价需额外验证 R(A)=R(A,B)

**适合题型：** single_choice, true_false

#### 知识点 2-5-4

**知识点名称：** Sylvester秩不等式（拓展）

**所属章节：** 第二章 行列式

**所属小节：** 2.5 矩阵的秩

**教学层级：** 拓展提高

**是否建议进入第一版网页：** 否

**一句话理解：** R(A)+R(B)-n ≤ R(AB) ≤ min{R(A),R(B)}，其中n为A的列数=B的行数。

- R(A)+R(B)-n ≤ R(AB)（n为A的列数=B的行数）
- AB=O ⇒ R(A)+R(B) ≤ n

**适用条件：** A的列数等于B的行数（设为n）。

**常见易错点：** 不等号方向、n的含义。

#### 知识点 4-2-1

**知识点名称：** 向量组线性相关与线性无关的定义和判定

**所属章节：** 第四章 n维向量空间

**所属小节：** 4.2 向量组的线性相关性

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 存在不全为零的系数使组合为零 → 线性相关；只有全零系数 → 线性无关。用矩阵秩判定最可靠。

**核心内容：**
(1) 定义：α_1,…,α_n 线性相关 ⇔ 存在不全为零的数 k_i 使 Σk_i α_i = 0；线性无关 ⇔ 只有 k_1=…=k_n=0。
(2) 矩阵判定法：将向量组排成矩阵 A = (α_1,…,α_n)，则线性相关 ⇔ R(A) < n ⇔ Ax=0 有非零解；线性无关 ⇔ R(A) = n ⇔ Ax=0 只有零解。
(3) β 可由 α_1,…,α_n 线性表出 ⇔ R(A) = R(A | β)。

**关键公式：**
- Σk_i α_i = 0（线性相关定义式）
- α_1,…,α_n 线性无关 ⇔ R(A) = n

**适用条件：** 向量维数与个数无直接关系（n维向量可以讨论任意m个向量的相关性）。

**常见易错点：**
- 混淆"线性相关"与"线性无关"的定义
- 把向量组和矩阵的秩直接比较时搞反方向（相关是 R < n，无关是 R = n）
- 忽略零向量的存在导致的所有向量组相关的情况

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材4.2（向量组的线性相关性，PDF第138页）；讲座 ch3-ch4-difficulties Page 2-3

#### 知识点 4-2-2

**知识点名称：** 线性相关/无关的对偶结论

**所属章节：** 第四章 n维向量空间

**所属小节：** 4.2 向量组的线性相关性

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是

**一句话理解：** 部分相关→整体相关；整体无关→部分无关。短向量无关（低维）→加长分量后仍无关；长向量相关（高维）→截短后仍相关。

**核心内容：**
两个对偶结论，方向均为单向：
(1) 个数关系（添加/删除向量）：若部分向量组(I)线性相关，则添加向量后整体(II)也线性相关；若整体(II)线性无关，则部分(I)也线性无关。反方向均不成立（整体相关⇏部分相关、部分无关⇏整体无关）。
(2) 维数关系（延长/截短分量）：若低维向量（每个向量仅取前r个分量）线性无关，则加上后面分量后仍线性无关；若高维向量（全部n个分量）线性相关，则去掉部分分量（截短）后仍线性相关。

**关键公式：** 无具体公式，以逻辑命题形式呈现。

**适用条件：** 任意向量组。

**常见易错点：**
- 反向推理："部分无关 ⇒ 整体无关"和"整体相关 ⇒ 部分相关"都是错的
- 延长/截短的方向关系容易搞反

**适合题型：** true_false, single_choice

**来源依据：** 讲座 ch3-ch4-difficulties Page 38-40；教材4.2

#### 知识点 4-2-3

**知识点名称：** 构造P矩阵法判断线性相关性

**所属章节：** 第四章 n维向量空间

**所属小节：** 4.2 向量组的线性相关性

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是

**一句话理解：** 将新向量组写成旧向量组的矩阵乘积 (β_1,…,β_m) = (α_1,…,α_n) P，P可逆则两组线性相关性一致。

**核心内容：**
已知 α_1,…,α_n 线性无关，欲判断 β_1,…,β_m 的线性相关性。构造矩阵P使得 (β_1,…,β_m) = (α_1,…,α_n)P。则 (1) 若P可逆（此时 m=n），β组与α组有相同的线性相关性；(2) 若P不可逆或m>n，β组一定线性相关。经典应用：判断 α_1+α_2, α_2+α_3, …, α_m+α_1 的无关性（m为奇数时线性无关、偶数时线性相关）。

- (β_1,…,β_m) = (α_1,…,α_n) P
- P可逆 ⇔ β组与α组有相同线性相关性

**适用条件：** α组必须已知线性无关（或相关）性。P的第j列是 β_j 在 α 组下的坐标。

**常见易错点：**
- 构造P时系数对应关系写反（P的第j列对应β_j的组合系数）
- P可逆性的判断（含参数时注意奇偶等条件）

**知识点名称：** 向量组的秩与极大无关组

**所属章节：** 第四章 n维向量空间

**所属小节：** 4.3 向量组的秩与极大无关组

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 向量组的秩 = 极大无关组所含向量个数 = 用这些向量拼成的矩阵的秩。

**核心内容：**
(1) 极大无关组：向量组中一个线性无关的部分组，且再添入任何别的向量都变为线性相关。(2) 向量组的秩：极大无关组所含向量的个数。记作 R(α_1,…,α_m)。(3) 计算方法：将向量写成矩阵 A = (α_1,…,α_m)，R(α_1,…,α_m) = R(A)。(4) 性质：等价向量组有相同的秩；秩为定值，极大无关组不唯一。(5) 线性表出关系：C=AB 意味着 C 的列可由 A 的列表出 → R(C) ≤ R(A)。

- C = AB ⇒ R(C) ≤ R(A)

**适用条件：** 任意向量组。

**常见易错点：**
- 极大无关组不唯一（但秩唯一）
- C=AB 中 C 的列由 A 的列表出（而非行表出）

#### 知识点 4-4-1

**知识点名称：** 齐次/非齐次线性方程组解的判定

**所属章节：** 第四章 n维向量空间

**所属小节：** 4.4 线性方程组解的结构

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 齐次Ax=0总有解（至少零解），唯一零解 ⇔ R(A)=n；非齐次Ax=b有解 ⇔ R(A)=R(A|b)。

**核心内容：**
(1) Ax=0（齐次）：总有解（至少x=0）。唯一零解 ⇔ R(A)=n（n为未知量个数=列数）；有非零解 ⇔ R(A)<n（有自由变量）。
(2) Ax=b（非齐次）：不一定有解。有解的充要条件：R(A) = R(A|b)。有解的前提下：唯一解 ⇔ R(A)=n；无穷多解 ⇔ R(A)<n。
(3) 自由变量个数 = n - R(A)，其中 n 为未知量个数。

**关键公式：**
- 自由变量个数 = n - R(A)
- Ax=b有解 ⇔ R(A) = R(A|b)

**适用条件：** A为m×n矩阵，n为未知量个数（=A的列数）。

**常见易错点：**
- "总有零解" ≠ "只有零解"（前者总成立，后者要求R(A)=n）
- 非齐次判解时忘记先看R(A)=R(A|b)
- 把系数矩阵的秩和增广矩阵的秩混淆

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材4.4（齐次/非齐次方程组，PDF第156页）；讲座 ch3-ch4-difficulties Page 41-42

**人工审核提醒：** 此知识点在第一章1.2（高斯消元）中已经出现，但完整的解结构理论在4.4。

#### 知识点 4-4-2

**知识点名称：** 基础解系与通解结构

**所属章节：** 第四章 n维向量空间

**所属小节：** 4.4 线性方程组解的结构

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** Ax=0的基础解系含 n-R(A) 个线性无关解向量；Ax=b通解 = 一个特解 + 导出组的基础解系的任意线性组合。

**核心内容：**
(1) 若 R(A)=r < n，则 Ax=0 存在基础解系，含 n-r 个线性无关的解向量。通解：ξ = k_1ξ_1 + … + k_(n-r)ξ_(n-r)（k_i为任意常数）。
(2) 若 R(A)=n，则 Ax=0 只有零解，无基础解系。
(3) Ax=b 的通解：η = η_0 + k_1ξ_1 + … + k_(n-r)ξ_(n-r)，其中 η_0 为任意一个特解（非齐次方程的一个解），ξ_i 为导出组的基础解系。
(4) 特解与基础解系中的解线性无关。

**关键公式：**
- dim(解空间W) = n - R(A)
- Ax=b 通解 = 特解 + 齐次通解

**适用条件：** R(A) = r < n 时才有基础解系（否则 n-r=0，只有零解）。

**常见易错点：**
- 基础解系向量个数 = n-r，不是 r（极易写反）
- 通解中要写"任意常数" k_i
- 非齐次通解要先写特解再加上齐次通解（漏写特解是最常见错误）

**适合题型：** basic_calculation, single_choice

**来源依据：** 教材4.4（齐次/非齐次方程组解的结构）；讲座 ch3-ch4-difficulties Page 41-43

**人工审核提醒：** 基础解系求法是考试高频内容，建议多出几道基础计算题。

#### 知识点 4-4-3

**知识点名称：** R(A^T A) = R(A) 的证明与应用

**所属章节：** 第四章 n维向量空间

**所属小节：** 4.4 线性方程组解的结构

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是

**一句话理解：** 对实矩阵A，Ax=0 与 A^T Ax=0 同解，故 R(A^T A) = R(A)。

**核心内容：**
证明：(1) Ax=0 ⇒ A^T Ax=0 (显然)。(2) A^T Ax=0 ⇒ x^T A^T Ax=0 ⇒ ‖Ax‖^2=0 ⇒ Ax=0。两解空间相等 ⇒ n-R(A)=n-R(A^T A) ⇒ R(A^T A)=R(A)。同理 R(AA^T)=R(A)。此结论保证 A^T Ax=A^T b 恒有解。

**关键公式：**
- R(A^T A) = R(A) = R(A A^T)
- Ax=0 与 A^T Ax=0 同解

**适用条件：** 实矩阵A（对复矩阵需用共轭转置 A^H）。

**常见易错点：** 该结论对实矩阵成立，对复矩阵需用共轭转置。

**适合题型：** single_choice, true_false

**来源依据：** 讲座 ch3-ch4-difficulties Page 43-45；教材4.4或2.5

**人工审核提醒：** 讲座中此结论出现了三次，属于横跨秩理论和方程组的重要结论。

### 第五章 特征值与特征向量

#### 知识点 5-1-1

**知识点名称：** 特征值与特征向量的定义与计算

**所属章节：** 第五章 特征值与特征向量

**所属小节：** 5.1 特征值与特征向量的概念与计算

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 若 Ax = λx（x≠0），则 λ 为特征值、x 为对应的特征向量。特征值由 |λI-A| = 0 求得。

**核心内容：**
(1) 定义：设 A 为 n 阶方阵，若存在数 λ 和非零向量 x 使 Ax = λx，则 λ 为 A 的特征值，x 为 A 的属于 λ 的特征向量。(2) 求法：解特征方程 |λI-A| = 0（或 |A-λI| = 0）得全部特征值。对每个 λ，解齐次方程组 (λI-A)x = 0 得全部特征向量（解空间去掉零向量）。(3) 性质：tr(A) = Σλ_i，|A| = Πλ_i。

**关键公式：**
- |λI-A| = 0（特征方程）
- tr(A) = Σλ_i（迹等于特征值之和）
- |A| = Πλ_i（行列式等于特征值之积）

**适用条件：** A为n阶方阵。特征向量不能为零向量。

**常见易错点：**
- 特征向量不能为零向量
- 特征多项式中 |λI-A| 和 |A-λI| 的符号（两者差 (-1)^n 倍，在偶数阶时相等）
- 重根时特征空间的维数可能小于代数重数

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材5.1（PDF第177页）

#### 知识点 5-2-1

**知识点名称：** 矩阵相似与相似对角化的条件

**所属章节：** 第五章 特征值与特征向量

**所属小节：** 5.2 矩阵的相似对角化

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** A可相似对角化 ⇔ A有n个线性无关的特征向量 ⇔ k重特征值的几何重数=代数重数。

**核心内容：**
(1) 相似的定义：存在可逆P使 P^(-1)AP = B。(2) 对角化：A可相似于一个对角矩阵 ⇔ 存在n个线性无关的特征向量。(3) 判别步骤：求全部特征值 → 若全为单根则一定可对角化 → 若有k重根则检验 R(λI-A) = n-k（几何重数=代数重数）→ 成立则可对角化。(4) 对角矩阵的构造：Λ = diag(λ_1,…,λ_n)，P的列为对应特征向量。

**关键公式：**
- k重根可对角化 ⇔ R(λI-A) = n-k
- P^(-1)AP = diag(λ_1, …, λ_n)

**适用条件：** A为n阶方阵。

**常见易错点：**
- k重特征值不自动保证k个线性无关的特征向量
- 几何重数 ≤ 代数重数，必须验证是否等于

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材5.2（相似对角化，PDF第184页）；讲座 lecture Page 68-70

#### 知识点 5-3-1

**知识点名称：** 施密特正交化与正交矩阵

**所属章节：** 第五章 特征值与特征向量

**所属小节：** 5.3 n维向量空间的正交性

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 施密特正交化将线性无关向量组变为标准正交向量组；正交矩阵满足 Q^T Q = I。

**核心内容：**
(1) 标准正交向量组：每个向量是单位向量且两两正交。(2) 施密特正交化：对线性无关向量组 α_1,…,α_m，递推构造 β_k = α_k - Σ(⟨α_k,β_i⟩/⟨β_i,β_i⟩)β_i，再单位化 γ_i = β_i/‖β_i‖ 得标准正交基。(3) 正交矩阵：Q^T Q = I，Q^T = Q^(-1)。正交矩阵的列（行）向量构成标准正交基；|Q| = ±1；正交变换保持向量长度和内积不变。

**关键公式：**
- β_k = α_k - Σ_{i=1}^{k-1} (⟨α_k,β_i⟩/⟨β_i,β_i⟩) β_i
- Q^T Q = I，Q^T = Q^(-1)

**适用条件：** 施密特正交化要求原向量组线性无关。

**常见易错点：**
- 正交化公式中的减号方向
- 做完正交化后未做单位化
- 忘记最终的验证：Q^T Q = I

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材5.3（施密特正交化，PDF第195页）

**人工审核提醒：** 施密特正交化的3维计算题是常见考试题型。

#### 知识点 5-4-1

**知识点名称：** 实对称矩阵的正交相似对角化

**所属章节：** 第五章 特征值与特征向量

**所属小节：** 5.4 实对称矩阵的相似对角化

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是

**一句话理解：** 实对称矩阵一定可正交对角化：∃ 正交矩阵Q使 Q^T AQ = diag(λ_1,…,λ_n)。

**核心内容：**
(1) 实对称矩阵的三条特殊性质：特征值全为实数；不同特征值的特征向量正交；一定可相似对角化且过渡矩阵可选为正交矩阵。(2) 计算步骤：求特征值和特征向量 → 对重根的特征向量施密特正交化 → 全部单位化 → 排成正交矩阵 Q。(3) 最终形式：Q^T AQ = Q^(-1) AQ = diag(λ_1,…,λ_n)。(4) 与普通矩阵对角化的对比：普通矩阵不一定能对角化，实对称一定能。

**关键公式：**
- Q^T AQ = Q^(-1) AQ = diag(λ_1,…,λ_n)（Q为正交矩阵）
- 实对称矩阵：不同λ的特征向量正交

**适用条件：** A必须是实对称矩阵。

**常见易错点：**
- 把实对称矩阵的性质套用到普通矩阵
- 重根时忘记对特征向量做施密特正交化
- 正交矩阵要求所有列是单位向量且两两正交

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材5.4（PDF第198页）；讲座 lecture Page 68-70

**人工审核提醒：** 实对称矩阵与普通矩阵的对比适合放入"易错点"板块。

#### 知识点 6-1-1

**知识点名称：** 二次型及其矩阵表示、标准形与规范形

**所属章节：** 第六章 二次型与二次曲面

**所属小节：** 6.1 实二次型及其标准形

**教学层级：** 基础必学

**是否建议进入第一版网页：** 是

**一句话理解：** 二次型 f = x^T Ax（A为实对称矩阵），通过正交变换或配方法化为只含平方项的标准形。

**核心内容：**
(1) 定义：n元二次型 f(x_1,…,x_n) = Σ a_ij x_i x_j = x^T Ax，其中A为实对称矩阵。(2) 标准形：只含平方项（无交叉项）。化标准形的方法：正交变换法（利用5.4的结论，x=Qy ⇒ f=y^T Λ y = Σ λ_i y_i^2）或配方法（拉格朗日配方法）。(3) 规范形：系数仅为 +1, -1, 0，由正负惯性指数唯一确定。(4) 在 ‖x‖=1 约束下，f 的最大值为 A 的最大特征值。

**关键公式：**
- f = x^T Ax（A为实对称矩阵）
- 正交变换后：f = Σ λ_i y_i^2
- max_{‖x‖=1} x^T Ax = λ_max(A)

**适用条件：** A必须为实对称矩阵。

**常见易错点：**
- 标准形系数不等于特征值（仅在正交变换下相等）
- 规范形系数只能是 +1, -1, 0

**适合题型：** single_choice, basic_calculation

#### 知识点 6-2-1

**知识点名称：** 正定二次型的定义与判定

**所属章节：** 第六章 二次型与二次曲面

**所属小节：** 6.2 正定二次型

**教学层级：** 考试常见

**是否建议进入第一版网页：** 是

**一句话理解：** 对任意 x≠0 有 f(x) > 0 ⇔ A正定，可由顺序主子式、特征值或惯性指数判定。

**核心内容：**
三种等价判定方法：(1) 霍尔维茨定理：A的各阶顺序主子式均大于零。(2) 特征值法：A的所有特征值均大于零。(3) 惯性指数法：正惯性指数 = n。半正定：f(x) ≥ 0 且存在非零x使等于0。负定：-A正定。不定：f(x)有正有负。

**关键公式：**
- 正定 ⇔ 顺序主子式 > 0
- 正定 ⇔ λ_i > 0 (i=1,…,n)
- 正定 ⇔ 正惯性指数 = n

**适用条件：** A为实对称矩阵。

**常见易错点：**
- 顺序主子式与一般主子式的区别（顺序主子式是从左上角依次取1×1,2×2,…,n×n）
- 仅一个主子式>0不保证正定，需所有顺序主子式

**适合题型：** single_choice, true_false, basic_calculation

**来源依据：** 教材6.2（正定二次型，PDF第223页）
