### 下一批最适合进入网页主线的是哪一章？

### 为什么选它？

1. **与第一章衔接最自然**。第一章以逆矩阵结尾——逆矩阵的定义涉及行列式非零（A^(-1) = A*/|A|），第二章恰好在此时引入行列式定义和性质，形成"矩阵→初等变换→逆矩阵→行列式"的完整线索。

2. **教材结构明确、归属清晰**。第二章分为5个节次（定义→性质计算→拉普拉斯→克拉默→秩），每节独立性强，适合分节入库，不会出现跨章混淆。

4. **对考试帮助大**。拉普拉斯定理和克拉默法则是用户确认的"重点考点"，第二章整体的考试权重远高于等几何空间（第三章）。

5. **不需要复杂图形**。行列式和秩的内容几乎不需要空间想象或几何图形，纯文字+公式即可展示，适合当前 Demo 的技术栈。

### 候选 1

**知识点名称：** n阶行列式的定义（含二阶、三阶行列式基本计算）

**所属章节：** 第二章 行列式

**所属小节：** 2.1 n阶行列式的定义

**教学层级：** 基础必学

**是否建议进入当前 Demo 主线：** 是

**优先级：** P1

**一句话理解：** 行列式是方阵对应的一个数值，二阶为 ad-bc，n阶为 n! 项取自不同行不同列元素的代数和。

**核心内容：**
行列式是方阵对应的数值。二阶：|a b; c d| = ad-bc。三阶：可用对角线法则（萨吕法则），三阶以上不能。n阶：n! 项，每项取 n 个不同行不同列的元素相乘，正负由列标排列的奇偶性决定。余子式 M_ij（划去 i 行 j 列后的行列式），代数余子式 A_ij = (-1)^(i+j) M_ij。

**关键公式：**
- |a b; c d| = ad - bc（二阶行列式）
- |A| = Σ_{j=1}^{n} a_ij A_ij（按第i行展开，n≥2时）

**适用条件：** 仅方阵有行列式。

**常见易错点：**
- 三阶以上**不能**用对角线法则
- 代数余子式的 (-1)^(i+j) 符号容易忘
- 行列式是一个数，与矩阵（一张表）不同

**适合题型：** single_choice, true_false, basic_calculation

**为什么适合当前 Demo：** 是整个第二章的入口知识点，二阶/三阶计算简单，适合出选择+判断。与第一章的矩阵概念形成对照（"矩阵是一张表，行列式是一个数"）。

**人工审核提醒：** 教材定义中是否使用逆序数定义，还是直接从二阶三阶推广？网页展示需选择哪种定义方式。

### 候选 2

**知识点名称：** 行列式的六大性质

**所属章节：** 第二章 行列式

**所属小节：** 2.2 行列式的性质与计算

**教学层级：** 基础必学

**是否建议进入当前 Demo 主线：** 是

**优先级：** P1

**一句话理解：** 六条性质（转置不变、换行变号、公因子提取、倍加不变、拆分、成比例为零）是化简和计算行列式的理论基础。

**核心内容：**
(1) 转置不变：|A^T| = |A|。(2) 换行变号。(3) 公因子提取：某行公因子 k 可提出 ⇒ |kA| = k^n|A|（注意 n 是阶数）。(4) 倍加不变：某行加上另一行的 k 倍。(5) 拆分行列式：某行为两数之和。(6) 两行成比例 ⇒ |A| = 0。这六条是后面拉普拉斯定理和克拉默法则的理论基础。

**关键公式：**
- |kA| = k^n |A|（n为阶数；易错：指数不是1）
- 两行成比例 ⇒ |A| = 0

**适用条件：** n 阶方阵。

**常见易错点：**
- |kA| = k^n|A| 的指数 n 容易被写成 1
- 倍加变换保持行列式不变，而公因子提取是提出因子（两条性质不同，容易用混）

**适合题型：** single_choice, true_false

**为什么适合当前 Demo：** 六条性质全是判断题素材。|kA| = k^n|A| 的反直觉性是绝佳的易错点。不需要计算，适合当前 Demo 的题型能力。

**人工审核提醒：** 教材中性质可能多于六条（如行列式为零的条件可能单独列为一条），请统一数量。

### 候选 3

**知识点名称：** 代数余子式与按行（列）展开

**所属章节：** 第二章 行列式

**所属小节：** 2.2 行列式的性质与计算

**教学层级：** 基础必学

**是否建议进入当前 Demo 主线：** 是

**优先级：** P2

**一句话理解：** 行列式可按任一行（列）展开为该行（列）各元素与其代数余子式乘积之和。

**核心内容：**
行列式按第 i 行展开：|A| = a_i1 A_i1 + a_i2 A_i2 + … + a_in A_in。A_ij = (-1)^(i+j) M_ij 是代数余子式，M_ij 是划去第 i 行第 j 列后的 n-1 阶行列式（余子式）。这一展开是拉普拉斯定理的特例（k=1）。选含零最多的行或列展开最省计算。

**关键公式：**
- |A| = Σ_{j=1}^{n} a_ij A_ij（按第i行展开，n≥2）
- A_ij = (-1)^(i+j) M_ij

**适用条件：** n≥2 的方阵；n=1 时退化为元素本身。

**常见易错点：**
- 余子式 M_ij（不带符号）和代数余子式 A_ij（带符号）的区别
- 展开公式中 a_ij 与 A_ij 的行列位置对应关系

**适合题型：** single_choice, true_false

**为什么适合当前 Demo：** 是拉普拉斯定理（候选4）的前置知识，适合先入库。选择+判断题型足够覆盖核心概念（符号规则、展开方向）。

**人工审核提醒：** 教材中余子式和代数余子式的记号（M_ij、A_ij）需与网页中矩阵元素标记统一。

### 候选 4

**知识点名称：** 拉普拉斯定理——按 k 行展开

**所属章节：** 第二章 行列式

**所属小节：** 2.3 拉普拉斯定理

**教学层级：** 考试常见

**是否建议进入当前 Demo 主线：** 是

**优先级：** P1

**一句话理解：** 行列式按任意 k 行展开 = 这些行中所有 k 阶子式与对应代数余子式乘积之和（重点考点）。

**核心内容：**
从 n 行中任选 k 行，取这些行中任意 k 列构成 k 阶子式 M_k，其代数余子式为 (-1)^(行标和+列标和) 乘以对应的 (n-k) 阶子式。所有 k 阶子式与代数余子式之和 = 原行列式。k=1 时退化为候选3（按一行展开）。重要应用：上三角分块行列式 = 各对角块行列式之积。

**关键公式：**
- D = Σ M_k · A_k
- 代数余子式符号：(-1)^(行标和+列标和)

**适用条件：** n 阶行列式，k 为 1 到 n-1 之间的整数。

**常见易错点：**
- 代数余子式的符号公式容易算错（经常漏写 (-1) 的指数）
- 子式的阶数和余子式的阶数搞反

**适合题型：** single_choice, true_false, basic_calculation

**为什么适合当前 Demo：** 用户确认为重点考点，且在第二章内部可独立讲解。定义类内容适合选择/判断，特殊情形（k=1 退化、k=n-1 分块对角）适合出计算类选择。

**人工审核提醒：** 教材中拉普拉斯定理的表述可能比讲座更严谨，需对照原文核实。

### 候选 5

**知识点名称：** 克拉默法则——用行列式解线性方程组

**所属章节：** 第二章 行列式

**所属小节：** 2.4 克拉默法则

**教学层级：** 考试常见

**是否建议进入当前 Demo 主线：** 是

**优先级：** P1

**一句话理解：** 若 |A|≠0，Ax=b 的唯一解为 x_i = |A_i|/|A|（A_i 为 A 第 i 列换成 b）（重点考点）。

**核心内容：**
用于求解 n 个方程 n 个未知数的 Ax=b，前提 |A|≠0。A_i 是将 A 第 i 列替换为常数向量 b。推论：齐次 Ax=0 有非零解 ⇔ |A| = 0。理论上说明了解的唯一性与行列式的等价关系。考试中通常考 n=3 的计算题。需注意：n 大时不实用（要算 n+1 个行列式）。

**关键公式：**
- x_i = |A_i| / |A|（**前提：|A|≠0**）
- Ax=0 有非零解 ⇔ |A| = 0

**适用条件：** A 为 n 阶方阵且 |A|≠0。

**常见易错点：**
- 忘记验证 |A|≠0 的前提（最常见）
- A_i 只换第 i 列，其余 n-1 列完全不变

**适合题型：** single_choice, true_false, basic_calculation

**为什么适合当前 Demo：** 与第一章"线性方程组解的判定"直接衔接——第一章用消元法判定，第二章用行列式判定。n=3 的计算题可出为选择题（给出四个选项）。推论（|A|=0 ⇔ 有非零解）是高频判断题素材。

**人工审核提醒：** 教材例题（PDF 第93页）可参考出题方向，但不可照搬原题。

### 候选 6

**知识点名称：** 伴随矩阵的定义与核心性质

**所属章节：** 第二章 行列式

**所属小节：** 2.2 行列式的性质与计算

**教学层级：** 考试常见

**是否建议进入当前 Demo 主线：** 是

**优先级：** P2

**一句话理解：** A* 是代数余子式的转置矩阵，满足 AA* = A*A = |A|I，借此可求逆矩阵。

**核心内容：**
定义：A* = (A_ji)，第 i 行第 j 列元素为 a_ji 的代数余子式（转置！）。基本关系 AA* = A*A = |A|I ⇒ 若 |A|≠0，则 A^(-1) = A*/|A|。|A*| = |A|^(n-1)。秩规律：R(A)=n→R(A*)=n；R(A)=n-1→R(A*)=1；R(A)<n-1→R(A*)=0。教材 PDF 第73页（2.2 节）。

**关键公式：**
- AA* = A*A = |A|·I
- |A*| = |A|^(n-1)
- A^(-1) = A*/|A|（|A|≠0 时）

**适用条件：** A 为 n 阶方阵（n≥2）。n=1 时单独定义。

**常见易错点：**
- 定义中"转置"这一步最容易被忽略
- |A*| 的指数是 n-1 不是 n
- R(A)=n-1 时 R(A*)=1 是一个特殊的中间状态

**适合题型：** single_choice, true_false

**为什么适合当前 Demo：** 与第一章逆矩阵（1.3）完美衔接：第一章用行变换求逆，此处用伴随矩阵求逆（公式法）。秩的三种情况特别适合出选择题。定义本身条件清楚、难度可控。

**人工审核提醒：** 伴随矩阵的秩规律涉及秩的概念（2.5），如果伴随矩阵入库在先，需在网页中简要说明秩的含义或加交叉引用。

### 候选 7

**知识点名称：** 矩阵秩的概念

**所属章节：** 第二章 行列式

**所属小节：** 2.5 矩阵的秩

**教学层级：** 基础必学

**是否建议进入当前 Demo 主线：** 是

**优先级：** P1

**一句话理解：** 矩阵的秩 = 行阶梯形非零行的行数，满足 0 ≤ R(A) ≤ min(m,n)，初等变换不改变秩。

**核心内容：**
秩的定义（两种等价表述）：(1) 不等于零的子式的最高阶数；(2) 行阶梯形中非零行的行数。基本性质：0 ≤ R(A) ≤ min(m,n)；R(A)=0 ⇔ A=O；若 P,Q 可逆，则 R(PA)=R(AQ)=R(A)；R(A^T)=R(A)；R(kA)=R(A)（k≠0）。秩的意义：AX=0 的自由变量个数 = n - R(A)。

**关键公式：**
- 0 ≤ R(A) ≤ min(m, n)
- R(PA) = R(A)（P 可逆时）
- 自由变量个数 = n - R(A)（n 为列数，即未知量个数）

**适用条件：** 秩的定义适用于任意矩阵（不限于方阵）。

**常见易错点：**
- 秩是整数，行列式是数值——概念上完全不同
- R(A+B) ≤ R(A)+R(B) 是上界不是等号
- R(PA)=R(A) 只在 P 可逆时成立

**适合题型：** single_choice, true_false

**为什么适合当前 Demo：** 是第四章 n 维向量空间的必备前置。与第一章"初等变换保秩"直接衔接。秩的性质适合出判断题。自由变量个数的公式与解方程组直接关联。

**人工审核提醒：** Sylvester 不等式（拓展提高）暂不入库，不要在秩的基础内容中包含它。

### 候选 8

**知识点名称：** 矩阵秩的计算方法

**所属章节：** 第二章 行列式

**所属小节：** 2.5 矩阵的秩

**教学层级：** 基础必学

**是否建议进入当前 Demo 主线：** 暂缓（建议与候选7合并为"秩的概念与计算"）

**优先级：** P2

**一句话理解：** 用行初等变换将矩阵化为行阶梯形，非零行的行数即为秩。

**核心内容：**
求秩的标准方法：对矩阵作行初等变换 → 化为行阶梯形 → 非零行行数 = R(A)。也可以用列初等变换（秩不变），但通常只用行变换更方便。特殊情形：方阵的秩 = n（满秩）⇔ 行列式不为零；n 阶方阵的秩 < n ⇔ 行列式为零。

**关键公式：**
- R(A) = 行阶梯形非零行数
- n 阶方阵满秩 ⇔ |A| ≠ 0

**适用条件：** 对任意 m×n 矩阵均适用。

**常见易错点：**
- 行阶梯形无需化为行最简形，只要每行首元逐行右移即可
- 求秩时行初等变换和列初等变换都可以用（与解方程组不同）

**适合题型：** basic_calculation, single_choice

**为什么适合当前 Demo：** 与候选7（秩的概念）紧密配套。但此知识点最适合的题型是计算题（给矩阵求秩），当前 Demo 的题型以选择/判断为主。建议与候选7合并为一个知识点，通过"给定阶梯形选秩"的选择题来覆盖。

**人工审核提醒：** 建议合并为"矩阵秩的概念与计算"，简化入库数量。

**适用条件：** 分别适用于不同结构的行列式。

**常见易错点：** 倍加运算中只改变被加行，另加行不变。

**适合题型：** basic_calculation

**为什么适合当前 Demo：** 虽是考试常见，但最适合的题型是计算题（给行列式求值），当前 Demo 的选择/判断题不足以覆盖计算过程。建议暂缓，待 Demo 支持计算题输入后再入库。

### 候选 10

**知识点名称：** 可逆矩阵的等价条件——用行列式和秩判断可逆性

**所属章节：** 第二章 行列式

**所属小节：** 2.5 矩阵的秩

**教学层级：** 考试常见

**是否建议进入当前 Demo 主线：** 暂缓（是跨节总结性内容，建议在 2.2+2.5 入库后再作为总结知识）

**优先级：** P3

**一句话理解：** n 阶方阵 A 可逆 ⇔ |A|≠0 ⇔ R(A)=n ⇔ Ax=0 仅有零解。

**核心内容：**
十个等价条件将第一章的逆矩阵概念与第二章的行列式、秩串联起来：(1)存在逆矩阵 → (2)行列式非零 → (3)秩 = n → (4)齐次仅有零解 → (5)非齐次有唯一解 → (6)等价于单位矩阵 → …… 共计十个等价命题。

**关键公式：**
- A 可逆 ⇔ |A| ≠ 0 ⇔ R(A) = n ⇔ Ax=0 仅有零解

**适用条件：** 仅适用于方阵。

**常见易错点：** 非方阵不能套用。

**适合题型：** single_choice, true_false
