# 备忘录与资料投稿说明

更新时间：2026-09-17

## 备忘录

当前版本使用浏览器 `localStorage` 保存备忘录，因此数据只保存在当前设备、当前浏览器中。

- 可新建、完成和删除备忘录。
- 备忘录按创建时间倒序展示。
- 当天新建且仍未完成的备忘录，会在本网站保持打开的前提下，于 21:00、22:00 分别弹出一次小助教提醒。
- 用户可主动授权浏览器系统通知；不授权时仍保留站内弹窗。

当前限制：关闭网页、关闭浏览器或换设备后，Demo 无法可靠推送提醒。后续如要实现跨设备和离线提醒，需要加入账号系统、数据库、服务器定时任务与推送服务。

## 资料专题与投稿

资料页采用“课程专题封面 -> 章节筛选 -> 资料卡片”的组织方式。当前第一个专题是“电科线性代数资料书架”。

投稿窗口支持选择 `.pdf`、`.doc`、`.docx`、`.md` 文件并填写说明，但 Demo 阶段只登记以下元数据：

- 文件名
- 标题
- 说明
- 提交时间
- 待审核状态

浏览器不会上传、存储或公开原文件。管理员审核后，应在有受控存储与权限管理的后台手动接收原文件，并决定是否：

1. 拒绝或要求补充授权说明。
2. 仅作为内部内容校对参考。
3. 改写整理为平台自制笔记、公式卡或思维导图。
4. 制作课程专题封面与资料卡后发布。

所有公开资料都应确认分享权限与版权边界，避免直接公开教材、教师课件或未经授权的题库。
