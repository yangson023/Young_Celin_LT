# 学习平台体验参考

这份清单不是“排名”，而是几类值得体验的学习产品。建议你们各自用 20 到 30 分钟走完一个学习流程，再把可借鉴点记录到 GitHub Issue；不要照搬视觉、文案、题目或课程内容。

## 1. Khan Academy 与 Khanmigo

- 访问：[Khan Academy](https://www.khanacademy.org/)；[Khanmigo](https://www.khanacademy.org/khan-labs)
- 借鉴重点：课程路径、掌握度、练习后的下一步建议，以及偏启发式的 AI 辅导。
- 对本项目的启发：把“下一步学什么”做得明确。你们已经有章节页和知识点页，下一轮可以优先做“本章推荐下一知识点”和“错题后先看哪个速讲”。
- 不宜直接照搬：完整的大规模课程体系和教师/班级功能。

## 2. Brilliant

- 访问：[Brilliant](https://brilliant.org/)
- 借鉴重点：把解释拆成很小的互动步骤，在题目中即时反馈，不急于直接揭示答案；其学习路径把知识按前后依赖串联。
- 对本项目的启发：第六章二次曲面和第五章特征向量特别适合增加一张小图或一个微交互，而不是只增加更多文字。
- 不宜直接照搬：高成本的全屏动画与完整游戏化体系。第一版做一两个高价值可视化即可。

## 3. Quizlet

- 访问：[Quizlet Learn](https://quizlet.com/features/learn)；[AI 学习工具](https://quizlet.com/features/ai-study-tools)
- 借鉴重点：把笔记转为多种复习形式，并依据错题和学习历史做短小、有目标的练习。
- 对本项目的启发：后续 AI 接入时，优先做“从已审核知识点生成 2 道同类补练”和“公式卡快速回顾”，不要先做没有边界的万能聊天框。
- 不宜直接照搬：未审核的资料直接自动进入正式题库；你们仍要保留人工审核和可编辑的草稿环节。

## 4. 学堂在线

- 访问：[学堂在线课程目录](https://www.xuetangx.com/university/all)；[课程 Studio 介绍](https://studio.xuetangx.com/)
- 借鉴重点：清晰的“课程—章节—小节—学习单元”结构，以及视频、文本、讨论、习题组合的课程组织方式。
- 对本项目的启发：你们当前的课程包结构已经很接近这一层级。后续可为每个知识点增加固定的“速讲—例子—自测—错题回顾”小单元，不必过早做复杂后台。
- 不宜直接照搬：面向教师的发布、日历、班级和数据分析体系；这不属于当前小范围试点的必要能力。

## 建议的体验任务

1. 体验 Brilliant 的一节数学课：记录它何时给提示、何时给答案。
2. 用 Quizlet 把一小段自制笔记转成练习：记录它如何把材料拆成不同练习形式。
3. 浏览学堂在线的课程目录：记录章节与小节在手机端怎样保持可扫描。
4. 回到本站，把每一项观察转成一个具体问题，例如“第六章椭球面能否在 10 秒内看懂？”
