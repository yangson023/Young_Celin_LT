# 今日复习、错因标签与章节挑战

更新时间：2026-09-18

## 今日复习

错题记录会保存在浏览器 `localStorage`。每次做错后，题目进入“今日回顾”。之后的复习节奏是固定且透明的：

```text
初次做错 -> 今日回顾
今日答对 -> 3 天后复习
3 天后答对 -> 7 天后巩固
7 天后答对 -> 移出错题本
任一轮再次答错 -> 回到今日回顾
```

这样做借鉴了间隔复习的思路，但不引入复杂推荐算法，方便试点阶段解释、验证和调整。

## 错因标签

学生在每道错题的解析下可选择一个主要错因：

- 概念不清
- 条件漏看
- 公式记错
- 计算失误
- 符号混淆

标签目前用于错题本中的回顾和人工观察。后续收集到足够试用数据后，再决定是否按错因生成专项练习或学习建议。

## 章节挑战

章节挑战从本章不同知识点中优先各取一道题，并补足到最多 10 题。

- 结果页按知识点显示“本次掌握”与“建议回看”。
- 章节页保留该章节最近一次挑战的分数。
- 挑战中的错题仍按原知识点进入错题本和复习队列。

## 当前边界

- 所有记录仅在当前浏览器中保存，换设备或清理浏览器数据后会丢失。
- 当前固定使用当天、3 天、7 天的节奏；不做个人记忆曲线预测。
- 章节挑战仍只使用人工审核的客观题。
