## 1.1 矩阵及其运算

提取出的核心知识：

- 矩阵概念与元素位置。
- 同型矩阵、矩阵相等。
- 零矩阵、方阵、单位矩阵、对角矩阵、三角矩阵等特殊矩阵。
- 矩阵线性运算：加法、负矩阵、减法、数乘。
- 矩阵乘法及其阶数条件。
- 方阵的幂与方阵多项式。
- 矩阵转置。
- 对称矩阵与反对称矩阵。

网页知识点：

```text
矩阵概念与特殊矩阵
矩阵线性运算
矩阵乘法
方阵的幂与多项式
矩阵转置与对称矩阵
```

## 1.2 高斯消元法与矩阵的初等变换

提取出的核心知识：

- 线性方程组的矩阵形式。
- 齐次方程组与非齐次方程组。
- 增广矩阵。
- 行初等变换与高斯消元。
- 行阶梯形与简化行阶梯形。
- 方程组解的判定。
- 矩阵等价。
- 初等矩阵。
- 行变换对应左乘初等矩阵，列变换对应右乘初等矩阵。

网页知识点：

```text
线性方程组的矩阵形式
高斯消元与阶梯形矩阵
方程组解的判定
矩阵初等变换与等价
初等矩阵
```

## 1.3 逆矩阵

- 可逆矩阵与初等矩阵、初等变换之间的关系。
- 可逆矩阵的等价判定。
- 用行初等变换求逆矩阵。

逆矩阵的概念与性质

提取出的核心知识：

- 分块矩阵的加法、数乘、乘法。
- 分块矩阵的转置。
- 分块对角矩阵及其逆。
- 分块思想在矩阵计算中的简化作用。
